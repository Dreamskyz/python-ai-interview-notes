# Python AI 应用开发校招学习笔记

> 面向大模型应用开发岗位的结构化学习笔记：从 Python 基础出发，逐步覆盖工程化、FastAPI、并发、RAG 与面试表达。

## 为什么建立这个仓库

聊天适合学习和追问，但不适合长期检索。本仓库把每次学习沉淀为可搜索、可复习、可持续迭代的 Markdown 笔记，同时记录练习、易错点和面试回答。

## 学习路线

| 阶段 | 内容 | 目标 |
| --- | --- | --- |
| 00 | 学习路线与进度 | 明确顺序，持续复盘 |

| 07 | 并发与异步 | 理解线程、进程和 async/await |
| 08 | FastAPI | 能开发结构清晰、可测试的 API |
| 09 | RAG 开发 | 串联切分、检索、精排、生成与评测 |
| 10 | 面试与复盘 | 把知识转化为清晰的面试表达 |

## 单篇笔记模板

每篇笔记尽量包含：

1. 一句话结论
2. 原理与设计理由
3. 带关键中文注释的示例代码
4. 常见误区与排查方法
5. 练习题与答案
6. 面试回答版本
7. 与 AI 应用开发的联系

## 学习原则

- 先理解原理，再写代码。
- 重要代码保留关键中文注释。
- 每章都留下可以直接用于面试的表达。
- 不记录任何真实密钥、令牌或个人敏感信息。
- 笔记追求“自己能解释”，而不是堆砌资料。
