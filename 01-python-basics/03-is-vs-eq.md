# `is`、`==` 与 `id()`

## 1. 本节定位

- 🔴 必须掌握：对象身份和值相等的区别
- ⭐ 高频面试：`is` 与 `==`、为什么使用 `is None`
- 🟢 工程规范：普通值比较使用 `==`，单例判断使用 `is`

## 2. 核心结论

> `==` 主要判断两个对象的值是否相等；`is` 判断两个引用是否指向同一个对象；`id()` 是观察对象身份的工具。

```python
a = [1, 2]
b = [1, 2]
c = a

print(a == b)  # True：值相等
print(a is b)  # False：是分别创建的两个列表对象
print(a == c)  # True：同一对象的值当然相等
print(a is c)  # True：指向同一个对象
```

## 3. `==`：比较值是否相等

`==` 关心对象表达的内容是否相等。两个不同列表的内容可以相同：

```python
a = [1, 2]
b = [1, 2]

print(a == b)  # True
```

对于自定义类，`==` 的行为与 `__eq__()` 特殊方法有关，这会在面向对象章节展开。

## 4. `is`：比较对象身份

```text
a ───→ List A [1, 2]
b ───→ List B [1, 2]
c ───→ List A [1, 2]
```

因此，`a is b` 为 `False`，而 `a is c` 为 `True`。`is` 不是“更严格的值比较”，它回答的是另一个问题：是否为同一个对象。

## 5. `id()` 与对象身份

```python
a = [1, 2]
c = a

print(id(a))
print(id(c))
```

在对象存活期间，同一个对象具有相同的 `id()`。更严谨的表达是：

> `is` 比较对象身份；`id()` 是观察对象身份的工具。

不要把概念倒过来说成“`is` 比较两个 `id()`”。另外，`id()` 的唯一性针对对象生命周期；对象销毁后，其标识值未来可能被复用。

## 6. 为什么使用 `is None`

`None` 表示没有值、缺失或尚未得到结果，并且它是单例对象：

```python
document = None

if document is None:
    print("没有找到文档")
```

推荐 `is None` 有两个原因：

1. 语义准确：判断对象是否就是唯一的 `None`。
2. 不依赖对象自定义的相等比较逻辑。

反向判断使用 `is not None`。

## 7. 为什么不要用 `is` 比较普通值

错误示例：

```python
name = "RAG"

if name is "RAG":  # 不应这样比较字符串值
    ...
```

正确写法：

```python
if name == "RAG":
    ...
```

Python 实现可能对部分整数或字符串复用对象，使某些 `is` 比较偶然返回 `True`。这是实现优化，不能作为业务逻辑依据。

- 比较普通值：使用 `==` / `!=`
- 判断 `None` 等明确单例：使用 `is` / `is not`

## 8. 常见误区

### 误区一：值相等就是同一个对象

两个分别创建的列表可以值相等，但身份不同。

### 误区二：`is` 比 `==` 更严格，所以比较值时更好

两者判断的问题不同，不存在这种替代关系。

### 误区三：小整数 `is` 得到 `True`，所以可以用 `is` 比整数

这是对象复用带来的偶然现象，不是可靠的数值比较规则。

## 9. AI / RAG / FastAPI 场景

检索结果中，`0.0` 可能是合法分数，而 `None` 表示尚未计算：

```python
retrieval_score: float | None = None

if retrieval_score is None:
    # 只处理“尚未计算”，不会把合法的 0.0 误判为缺失
    ...
```

业务值比较则使用 `==`：

```python
document_status = "active"

if document_status == "active":
    ...
```

## 10. 面试专区

### Q1：`is` 和 `==` 有什么区别？

> `==` 主要判断两个对象的值是否相等，而 `is` 判断两个变量引用的是不是同一个对象，也就是比较对象身份。两个分别创建的列表内容都为 `[1, 2]` 时，`==` 可以是 `True`，但 `is` 是 `False`。普通值比较应该使用 `==`，而判断 `None` 通常使用 `is None`。

### Q2：为什么判断 `None` 使用 `is None`？

> 因为 `None` 是单例对象，我们要判断的正是对象是否为这个唯一的 `None`。`is` 直接比较对象身份，而且不会受到自定义 `__eq__()` 行为影响。

### Q3：两个值相等的对象一定是同一个对象吗？

> 不一定。例如 `a = [1, 2]`、`b = [1, 2]`，`a == b` 为 `True`，但它们是两个列表，所以 `a is b` 为 `False`。

### Q4：为什么两个相同的小整数使用 `is` 有时是 `True`？

> Python 实现可能缓存或复用部分不可变对象。这是实现优化，不应该依赖；数值是否相等必须使用 `==`。

### Q5：`==` 的底层行为由什么决定？

> 对自定义对象来说，`==` 的行为通常由类的 `__eq__()` 特殊方法决定；`is` 不调用值比较逻辑，只判断对象身份。

## 11. 我的练习与易错点

```python
a = [1, 2]
b = [1, 2]
c = a
```

正确结果：

```python
a == b  # True
a is b  # False
a == c  # True
a is c  # True
```

曾在书写答案时把 `a is c` 写成 `False`，但引用关系解释正确。复查时应从“是否指向同一个对象”逐步推导，不只凭直觉填写布尔值。

## 12. 一分钟复习

- `==` 比较值，`is` 比较对象身份。
- `id()` 用来辅助观察对象身份。
- 值相等不代表是同一个对象。
- 普通值使用 `==`，不要依赖整数或字符串的对象复用。
- 判断空值使用 `value is None` 或 `value is not None`。
- 自定义对象的 `==` 通常与 `__eq__()` 有关。
