# 变量、对象与引用

## 1. 本节定位

- 🔴 必须掌握：变量名、对象、引用、赋值和重新绑定
- ⭐ 高频面试：`a = b` 是否复制对象、修改对象与重新赋值的区别
- 🟢 项目基础：理解函数传参、配置对象共享和检索结果修改

## 2. 核心结论

> Python 中的变量不是装值的盒子，而是绑定到对象的名字。赋值语句建立或改变“名字 → 对象”的绑定关系。

每个 Python 对象都可以从三个角度理解：

```text
Python 对象
├── identity：对象身份
├── type：对象类型
└── value：对象的值
```

## 3. 变量名如何引用对象

```python
age = 22
```

更准确的理解是：Python 创建或取得整数对象 `22`，再让名字 `age` 指向它。

```text
age ───→ 22
          └── type: int
```

类型属于对象，而不是变量名。一个变量名之后可以重新绑定到其他类型的对象：

```python
value = 22       # value 指向 int 对象
value = "RAG"    # value 改为指向 str 对象
```

## 4. 赋值不会自动复制对象

```python
a = [1, 2]
b = a
```

`b = a` 并没有创建新列表，而是让 `b` 也指向 `a` 当前引用的对象：

```text
a ─────┐
       ↓
    [1, 2]
       ↑
b ─────┘
```

```python
a.append(3)  # 修改两者共同引用的列表对象

print(a)  # [1, 2, 3]
print(b)  # [1, 2, 3]
```

## 5. 修改对象与重新绑定

### 5.1 修改对象本身

`a.append(3)` 修改原列表，两者仍然引用同一个对象：

```text
a ─────┐
       ↓
  [1, 2, 3]
       ↑
b ─────┘
```

### 5.2 让变量重新绑定

```python
a = [4, 5]
```

这不是把原列表变成 `[4, 5]`，而是让 `a` 指向新列表：

```text
a ───→ [4, 5]
b ───→ [1, 2, 3]
```

以后阅读代码时，可以主动问：这一行是在修改对象，还是在让名字重新绑定？

## 6. 常见误区

### 误区一：变量具有固定类型

错误心智模型是“`age` 是一个 `int` 盒子”。正确理解是对象具有类型，变量名只是引用对象。

### 误区二：`b = a` 会复制对象

对于列表等对象，普通赋值只会共享引用。如果需要独立对象，必须明确复制；复制的深浅会在后续章节学习。

### 误区三：重新赋值会影响其他变量

`a = 新对象` 只改变 `a` 的绑定，不会改变 `b` 的绑定，也不会修改旧对象。

## 7. AI / RAG / FastAPI 场景

```python
retrieved_chunks = ["chunk-1", "chunk-2"]
rerank_input = retrieved_chunks

# 原地修改共享列表，retrieved_chunks 也会受影响
rerank_input.append("chunk-3")
```

如果精排阶段不应该修改上游检索结果，就要意识到共享引用可能产生副作用，并明确接口是否需要复制输入。

## 8. 面试专区

### Q1：Python 中的变量是什么？

> Python 变量更准确地说是绑定到对象的名字。对象具有身份、类型和值；重新赋值改变的是名字的绑定，而不是把原对象直接变成另一个对象。

### Q2：`a = [1, 2]`，`b = a` 是否创建了两个列表？

> 没有。`a` 和 `b` 引用同一个列表对象，因此通过 `a.append()` 原地修改列表后，`b` 也能看到变化。

### Q3：`a.append(3)` 与 `a = [4, 5]` 有什么不同？

> `a.append(3)` 修改当前列表，共享该对象的其他变量也能观察到；`a = [4, 5]` 是让名字 `a` 重新绑定到新列表，其他变量仍可引用原列表。

### 追问：Python 是值传递还是引用传递？

这个问题将在函数章节完整回答。当前先记住：形参会绑定到实参所引用的对象；外部能否观察到变化，还取决于对象是否可变，以及函数内部是修改对象还是重新绑定形参。

## 9. 本节练习结论

```python
a = [1, 2]
b = a
a.append(3)
a = [4, 5]
```

最终关系：

```text
a ───→ [4, 5]
b ───→ [1, 2, 3]
```

## 10. 一分钟复习

- 变量是绑定到对象的名字。
- 对象具有 identity、type 和 value。
- 普通赋值不会自动复制对象。
- 原地修改影响共享同一对象的引用。
- 重新赋值只改变当前变量名的绑定。
