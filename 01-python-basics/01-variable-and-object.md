# 变量名、对象与引用

> Python 变量更准确地说是“绑定到对象的名字”，赋值通常是在建立或改变绑定关系。

## 核心概念

```python
a = [1, 2]
b = a
```

此时 `a` 和 `b` 指向同一个列表对象，而不是自动复制出两个列表。

## 修改对象与重新绑定

```python
a.append(3)  # 修改 a、b 共同指向的列表对象
a = [4, 5]   # 让名字 a 重新绑定到一个新列表
```

执行后，`a` 指向 `[4, 5]`，`b` 仍指向 `[1, 2, 3]`。

## 面试表达

赋值把变量名绑定到对象。原地修改会被所有共享该对象的引用观察到；重新赋值只改变当前名字的绑定。
