# 可变对象与不可变对象

> 可变性描述的是对象创建后，其内部状态能否改变。

- 常见不可变对象：`int`、`float`、`bool`、`str`、`tuple`
- 常见可变对象：`list`、`dict`、`set`

```python
x = "RAG"
y = x
x = x + " System"  # 创建新字符串并让 x 重新绑定，原字符串没有被修改
```

元组本身不可变，但它的元素可以引用可变对象。修改该可变对象，不等于替换元组中的元素引用。

```python
data = ([1, 2], "RAG")
data[0].append(3)  # 合法：修改列表
# data[0] = [4, 5]  # 报错：试图替换元组元素
```
